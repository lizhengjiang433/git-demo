# 指针

## 简介

pointer(p)

与底层硬件连接紧密→内存

实现数据的间接访问

线性区域，每个字节都有一个独一无二的地址

## 字节

int 4个字节，32个2进制（4×8=32）

```
0x12345678
```

小端（右边）放在内存地址低位，大端（左边）放在高位

这属于小端存储模式

> 针对超过1个字节的数据进行存储

数组地址从小到大（连续空间）顺序排列

| 数据类型 | 所占字节 |
| :------: | :------: |
|   char   |    1     |
|  short   |    2     |
|   int    |    4     |
|   long   |    4     |
|  float   |    4     |
|  double  |    8     |

对于int *p在64位系统所占字节为8字节，32位的是4字节

> 指针就是一个操作系统的地址

short，{0x1234,0x5678,......},单个数据按照小端存储，整体数据顺序连续存储



 指针也是变量，存变量的首地址



```
#第一个是指针，第二个是int
int *p,p1
#取地址
p=&a  int *p=&a
#取内容,解引用 
*p
```

指针变量运算

char *p++加一个数据宽度(2字节)

```
0x6244变成0x6246
```



## 数组

数组名就是指针，申请一块连续的内存

对于一个存了3个数据的数组，对应3个地址，这3个地址连续递增单位是1（因为char占1个字节）

```
#动态内存分配函数
int *a
//int a[]={0x34,0x56,0x78};
#a只负责记住这块内存从哪里开始
a=malloc(3*4)
//3个数据，1个数据占4个字节
*a=0x34
*(a+1)=0x56
*(a+2)=0x78
```

> ```
> void *malloc(size_t size);
> ```

保证地址合法再赋值

先给变量赋值，再给他指一个指针

同级指针可以相互赋值

```
int a = 5;
int *p = &a;
int **pp = &p;
```

传参、传返回值、传物理硬件地址

```
#把变量“地址”传进去，函数就能改到外面的变量
void swap(int *a, int *b) {
    int t = *a;
    *a = *b;
    *b = t;
}
```

```
#返回多个结果或者较大数据
void get_sum_and_avg(int a, int b, int *sum, float *avg) {
    *sum = a + b;
    *avg = (a + b) / 2.0f;
}
```

```
#把某个固定地址当成一个变量来访问，用来读写硬件数据
#define GPIO_DATA (*(volatile unsigned int *)0x40000000)
```

把`0x40000000` 这个地址强制转换成`unsigned int*` 指针

## 二级指针

```
#include <stdio.h>
int main(int argc,char **argv)
{
	if(argc >=2)
		printf("hello,%s!\n",argv[1]);
	else
		printf("hell,world!\n");
    return 0;
 }
```

char *：指向单个字符串

char ** ：指向一级指针的数组

一级指针 `char *` 存储字符串首字符的地址，比如 `"hello"` 中 `'h'` 的地址。
二级指针 `char **` 存储的是指向这些字符串指针的地址，也就是参数指针数组的地址。

argv 的类型是 char **
argv[0] 的类型是 char *，指向 "./my-first"
argv[1] 的类型是 char *, 指向 "hello"
argv[1][0] 才是字符 'h'
